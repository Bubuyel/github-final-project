# github-final-project

Final project for the Introduction to Git and GitHub course.

## Simple Interest Calculator

A Bash calculator that computes simple interest from user input: the principal amount, the annual rate of interest and the time period in years.

```
Input:
   p, principal amount
   r, annual rate of interest (%)
   t, time period in years
Output:
   simple interest = p*t*r/100
```

### Usage

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```
